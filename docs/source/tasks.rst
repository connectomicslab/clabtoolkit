What can you do with CLABTOOLKIT?
=================================

This page lists, by task, the problems that CLABTOOLKIT helps to solve. Each line gives the functions or
methods that do the work, and a link to the notebook of the module where they are shown with runnable
examples. The notebooks retrieve the sample data of clabtoolkit from its Zenodo repository, so they do not
need any input file.

A dagger (†) marks a function that is not yet illustrated in its notebook.

Colors and color tables
-----------------------

See the `colorstools notebook <https://github.com/connectomicslab/clabtoolkit/blob/main/usage_examples/examples-colorstools-methods.ipynb>`__.
* Generate sets of distinguishable colors for regions, groups or categories. :func:`create_distinguishable_colors <clabtoolkit.colorstools.create_distinguishable_colors>`, :func:`get_predefined_distinguishable_colors <clabtoolkit.colorstools.get_predefined_distinguishable_colors>`, :func:`create_random_colors <clabtoolkit.colorstools.create_random_colors>`. See the `colorstools notebook <https://github.com/connectomicslab/clabtoolkit/blob/main/usage_examples/examples-colorstools-methods.ipynb>`__.
* Convert values, region-wise or vertex-wise, to colors for consistent figures. :func:`values2colors <clabtoolkit.colorstools.values2colors>`, :func:`create_vertex_colors <clabtoolkit.freesurfertools.create_vertex_colors>`. * Invert, harmonize and readjust colors so that groups of regions stay distinguishable. :func:`invert_colors <clabtoolkit.colorstools.invert_colors>`, :func:`harmonize_colors <clabtoolkit.colorstools.harmonize_colors>`, :func:`readjust_colors <clabtoolkit.colorstools.readjust_colors>`. See the `colorstools notebook <https://github.com/connectomicslab/clabtoolkit/blob/main/usage_examples/examples-colorstools-methods.ipynb>`__.
* Visualize a set of colors or a color table before using it. :func:`visualize_colors <clabtoolkit.colorstools.visualize_colors>`, :func:`colortable_visualization <clabtoolkit.colorstools.colortable_visualization>`. * Collect colors into a table. :func:`colors_to_table <clabtoolkit.colorstools.colors_to_table>`. See the `colorstools notebook <https://github.com/connectomicslab/clabtoolkit/blob/main/usage_examples/examples-colorstools-methods.ipynb>`__.
* Print colored text in the terminal. :class:`bcolors <clabtoolkit.colorstools.bcolors>`. See the `colorstools notebook <https://github.com/connectomicslab/clabtoolkit/blob/main/usage_examples/examples-colorstools-methods.ipynb>`__.
